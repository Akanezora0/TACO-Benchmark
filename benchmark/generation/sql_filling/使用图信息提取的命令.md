# 使用图信息提取功能的命令

## 功能说明

现在填充脚本已经集成了图信息提取功能，可以自动从图文件中提取与SQL骨架相关的关键信息，大幅减小prompt大小。

## 使用方法

### 直接运行（自动使用图信息提取）

```bash
cd /home/u2023103807/TACO/benchmark/generation/sql_filling

python3 2fill_sql_placeholders_improved.py \
    --database_dir ../../data/beijing/database_chinese \
    --skeleton_dir ../../data/beijing/output/sql_skeleton \
    --graph_dir ../../data/beijing/output/graph_chinese \
    --output_dir ../../data/beijing/output \
    --max_retries 3
```

**工作流程：**
1. 脚本会自动检测图文件是否存在
2. 如果存在，从图文件中提取与SQL骨架相关的关键信息
3. 使用提取的信息构建精简版prompt（只包含相关表，最多5个表，每表最多10列）
4. 如果提取失败，自动回退到使用metadata文件或随机选择

## 优化效果

### 信息量对比

以"生活安全"数据库为例：

| 项目 | 原始图文件 | 提取后信息 | 压缩比 |
|------|-----------|-----------|--------|
| 表数量 | 24个 | 5个 | 4.8:1 |
| 列数量 | 681个 | 35个 | 19.5:1 |
| Prompt长度 | ~几万字符 | ~2000字符 | ~10:1 |

### 示例

**原始图文件包含：**
- 24个表节点
- 681个列节点
- 9582条sql-schema边

**提取后包含：**
- 5个相关表（与SQL骨架占位符直接连接的表）
- 35个相关列（这些表的列）
- 相关的外键关系（如果有）

## 参数调整

如果需要调整提取的参数，可以修改`2fill_sql_placeholders_improved.py`中的调用：

```python
extracted_info = extract_relevant_nodes_from_graph(
    G, sql_framework, 
    max_tables=5,        # 最多提取的表数量（默认5）
    max_columns_per_table=10  # 每张表最多提取的列数量（默认10）
)
```

## 注意事项

1. **自动回退**：如果图文件不存在或提取失败，会自动使用metadata文件或随机选择
2. **向后兼容**：不影响现有的metadata方式
3. **参数可调**：可以根据需要调整`max_tables`和`max_columns_per_table`参数
