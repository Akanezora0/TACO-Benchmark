由于跨数据库SQL生成成功率较低，建议使用迭代方式：

```bash

python3 6cleanup_failed_sqls.py

# 2. 备份有结果的SQL
python3 7backup_results.py

# 3. 重新生成
```

## 注意事项

1. **首次运行**: 需要先执行步骤1-3（分析表对、生成骨架、生成图）
2. **迭代生成**: 步骤4-5可以多次运行，会自动跳过已生成的SQL
3. **成功率**: 2数据库约80%，3数据库约24%，4数据库约100%（但样本少）
4. **时间**: 生成1,170条SQL可能需要较长时间，建议后台运行
