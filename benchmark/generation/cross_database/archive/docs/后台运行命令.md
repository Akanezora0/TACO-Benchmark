# JOIN版本SQL生成 - 后台运行命令

## 一、后台运行命令

### 方法1：使用完整流程脚本（推荐）

```bash
cd /home/u2023103807/TACO
nohup bash benchmark/generation/cross_database/run_join_generation_background.sh > benchmark/generation/cross_database/join_generation_background.log 2>&1 &
```

**说明**：
- `nohup`：让命令在后台运行，即使终端关闭也不会停止
- `> log文件`：将所有输出重定向到日志文件
- `2>&1`：将错误输出也重定向到日志文件
- `&`：在后台运行

### 方法2：手动执行单轮（用于测试或分步执行）

```bash
cd /home/u2023103807/TACO

# 步骤1: 清理没有结果的SQL文件
python3 benchmark/generation/cross_database/1cleanup_failed_sqls.py

# 步骤2: 重命名和组织SQL文件
python3 benchmark/generation/cross_database/2rename_and_organize.py

# 步骤3: 检查当前状态
python3 benchmark/generation/cross_database/3check_status.py

# 步骤4: 生成更多SQL
python3 benchmark/generation/cross_database/4generate_more_join_sqls.py
```

## 二、查看运行状态

### 查看实时日志
```bash
tail -f benchmark/generation/cross_database/join_generation_background.log
```

### 查看最新50行日志
```bash
tail -50 benchmark/generation/cross_database/join_generation_background.log
```

### 查看当前完成状态
```bash
python3 benchmark/generation/cross_database/3check_status.py
```

### 查看进程是否在运行
```bash
ps aux | grep run_join_generation_background
```

## 三、停止运行

### 查找进程ID
```bash
ps aux | grep run_join_generation_background | grep -v grep
```

### 停止进程（替换<PID>为实际进程ID）
```bash
kill <PID>
```

### 强制停止（如果普通kill无效）
```bash
kill -9 <PID>
```

## 四、运行流程说明

脚本会自动循环执行以下步骤：

1. **清理**：删除没有结果的SQL文件
2. **重命名**：按顺序重命名有结果的SQL文件（0, 1, 2, ...）
3. **检查状态**：统计当前完成情况
4. **生成更多**：选择未使用的骨架，生成新的SQL
5. **重复**：直到达到目标数量（2db: 359）或手动停止

## 五、目标数量

- **跨2个数据库**：359条（当前：51条，还需要308条）
- **跨3个数据库**：105条（当前：0条，还需要105条）
- **跨4个数据库**：2条（当前：0条，还需要2条）

## 六、注意事项

1. **成功率**：JOIN版本的成功率约22.5%，所以需要多次运行
2. **不重复**：脚本会自动避免重复生成相同的表对
3. **多样性**：每次随机选择未使用的骨架，确保多样性
4. **日志**：所有输出都会记录到日志文件中
