## 快速运行命令

### 方法1：单次运行（推荐，简单快速）

```bash
cd /home/u2023103807/TACO

# 步骤1: 清理
python3 benchmark/generation/cross_database/1cleanup_failed_sqls.py

# 步骤2: 重命名

# 步骤3: 检查状态
python3 benchmark/generation/cross_database/3check_status.py

# 步骤4: 生成更多（使用简化版，直接调用函数，不阻塞）
python3 benchmark/generation/cross_database/4generate_more_join_sqls_simple.py
```

**重复执行步骤1-4**，直到达到目标数量。

### 方法2：后台运行（自动循环）

```bash
cd /home/u2023103807/TACO
nohup bash benchmark/generation/cross_database/run_join_generation_background.sh > benchmark/generation/cross_database/join_generation_background.log 2>&1 &
```

**查看日志**：
```bash
tail -f benchmark/generation/cross_database/join_generation_background.log
```

**查看状态**：
```bash
python3 benchmark/generation/cross_database/3check_status.py
```

**停止运行**：
```bash
ps aux | grep run_join_generation_background
kill <PID>
```
