# 跨数据库查询数量计算

## 一、根据论文统计图计算目标数量

### 论文统计分布
- 跨1个数据库：80.5%（单数据库查询）
- 跨2个数据库：15.0%
- 跨3个数据库：4.4%
- 跨4个数据库：0.1%

### 计算步骤

1. **统计现有单数据库SQL数量**
   - 遍历所有beijing数据库
   - 统计每个数据库的SQL数量
   - 计算总和

2. **推算总查询数**
   - 总查询数 = 单数据库SQL数量 / 0.805

3. **计算各跨数据库查询数量**
   - 跨2个数据库 = 总查询数 × 0.15
   - 跨3个数据库 = 总查询数 × 0.044
   - 跨4个数据库 = 总查询数 × 0.001

## 二、实验计划

### 实验目标
选择几种跨数据库情况，生成200个SQL骨架，填充后统计成功率，以此确定每个跨库情况需要生成多少个骨架。

### 实验步骤

1. **选择跨数据库组合**
   - 跨2个数据库：选择2-3个不同的数据库组合
   - 跨3个数据库：选择1-2个不同的数据库组合
   - 跨4个数据库：选择1个数据库组合

2. **从单数据库SQL中选择候选**
   - 选择包含JOIN的SQL（至少2个表）
   - 每个组合选择200条

3. **生成跨数据库SQL骨架**
   - 将表分配到不同数据库
   - 生成跨数据库SQL骨架

4. **生成图文件**
   - 为跨数据库SQL生成图文件

5. **填充SQL**
   - 填充跨数据库SQL骨架
   - 统计成功率

6. **分析结果**
   - 计算成功率
   - 推算需要生成多少个骨架才能达到目标数量
