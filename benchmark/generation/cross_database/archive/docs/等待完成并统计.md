# 跨数据库SQL生成优化总结

## 优化措施

### 1. 使用ATTACH DATABASE功能
- 使用SQLite的ATTACH DATABASE功能，真正支持跨数据库查询
- 将"数据库名"."表名"转换为"别名"."表名"格式
- 在临时数据库中ATTACH所有涉及的数据库

### 2. 降级方案
- 如果ATTACH失败，尝试转换为单数据库格式执行
- 在涉及的数据库上依次尝试执行
